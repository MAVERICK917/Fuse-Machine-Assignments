# AI Fellowship Assignments — FuseMachine

This repository contains my weekly assignments, projects, experiments, and technical deliverables completed as part of my AI fellowship learning journey.

The purpose of this repository is to document my practical experience in **Artificial Intelligence (AI), Machine Learning (ML), software development, and MLOps**, while demonstrating how theoretical concepts can be applied to real-world problems.

## About the Fellowship

The AI fellowship focuses on developing practical technical skills through hands-on assignments and project-based learning. The work involves building AI-powered applications, experimenting with machine learning models, developing backend systems, and exploring the tools and workflows used to develop, evaluate, and deploy AI solutions.

Rather than focusing only on theory, these assignments emphasize implementation, experimentation, testing, evaluation, and documenting technical decisions.

## Learning Objectives

Through these assignments, I aim to develop the following skills:

- **Artificial Intelligence and Machine Learning:** Understand AI concepts and apply machine learning techniques to practical problems.
- **Data Processing and Analysis:** Work with datasets, prepare data, and interpret model results.
- **AI Application Development:** Build applications that integrate AI models and automated workflows.
- **Backend Development:** Develop APIs and supporting services using Python and relevant frameworks.
- **Model Evaluation:** Compare model performance, evaluate outputs, and identify areas for improvement.
- **MLOps:** Explore experiment tracking, model management, API-based model serving, and monitoring.
- **Software Engineering:** Apply Git, GitHub, testing, documentation, and structured project development practices.

## Repository Structure

Assignments are organized into weekly folders to keep the learning materials, source code, datasets, experiments, and reports organized.

```text
FuseMachine-Assignments/
├── Week 15/
├── Week 16/
├── Week 17/
├── Week 18/

```

*Note: The folders shown above represent the current assignment organization and may expand as more weeks are completed.*

Each weekly directory contains the relevant materials for its assignment, such as source code, notebooks, datasets, configuration files, tests, reports, and supporting documentation, depending on the task.


## Technologies and Tools

The technologies used vary by assignment and may include:

- **Programming:** Python
- **Machine Learning:** Scikit-learn and related ML libraries
- **Backend Development:** FastAPI
- **Experiment Tracking and Model Management:** MLflow
- **Monitoring and Evaluation:** Evidently and evaluation frameworks
- **Development and Testing:** Jupyter Notebook, automated tests, and Python tooling
- **Version Control:** Git and GitHub
- **Containerization:** Docker and Docker Compose, where required

The tools listed are based on the technologies used or explored in the relevant assignments; not every tool is used in every week.

## How to Explore the Repository

1. Browse the weekly assignment folders.
2. Read the README or instructions inside each folder, if available.
3. Review the notebooks, source code, and supporting documentation.
4. Check the tests and reports to understand how the implementation is evaluated.
5. Follow the setup instructions provided for each individual assignment before running its code.

Requirements and execution steps may differ between projects. Use the instructions in the relevant weekly folder as the primary guide.
